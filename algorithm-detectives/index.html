Your mission

What will you be able to do?

Explain what an algorithm achieves.

Explain how its variables, decisions and loops work.

Remember: Purpose = what it does. Process = how it does it.

00–05 minutes · Think–pair–share

Starter: What does this do?

Total ← 0
FOR Index ← 1 TO 5
    INPUT Number
    Total ← Total + Number
NEXT Index
OUTPUT Total

Discuss: What is its purpose? Why start Total at 0? What is the output for 4, 6, 3, 7, 5?

It inputs five numbers and outputs their sum: 25. Total starts at zero so the running sum is correct.
05–15 minutes · Group investigation

Activity 1: Three mystery algorithms

For each algorithm, identify its purpose, process, changing variables, output and method. Work with a partner before revealing the answers.

Mystery A
Count ← 0
FOR Index ← 1 TO 6
    INPUT Mark
    IF Mark >= 50 THEN
        Count ← Count + 1
    ENDIF
NEXT Index
OUTPUT Count

Inputs: 45, 72, 38, 90, 55, 41

Counts marks of at least 50. Increments Count for each qualifying mark. Output: 3. Method: counting.
Mystery B
Highest ← Numbers[1]
FOR Index ← 2 TO 5
    IF Numbers[Index] > Highest THEN
        Highest ← Numbers[Index]
    ENDIF
NEXT Index
OUTPUT Highest

Array: 12, 8, 25, 19, 6

Compares each number with the current highest and updates it if larger. Output: 25. Method: maximum.
Mystery C
Found ← FALSE
Position ← 1
WHILE Position <= 5 AND Found = FALSE
    IF Numbers[Position] = 17 THEN
        Found ← TRUE
    ELSE
        Position ← Position + 1
    ENDIF
ENDWHILE
OUTPUT Found

Array: 9, 14, 17, 21, 6

Checks each element in turn for 17 and stops when found. Output: TRUE. Method: linear search.

Activity 4: Algorithm challenge

A · What is the purpose?

Total ← 0
Count ← 0
FOR Index ← 1 TO 8
    IF Numbers[Index] > 20 THEN
        Total ← Total + Numbers[Index]
        Count ← Count + 1
    ENDIF
NEXT Index
IF Count > 0 THEN
    Average ← Total / Count
    OUTPUT Average
ELSE
    OUTPUT "No qualifying values"
ENDIF

Array: 10, 25, 30, 15, 40, 18, 50, 12

What is the purpose? What is the output? Why is Count > 0 necessary?

Finds the average of values greater than 20. Qualifying values: 25, 30, 40, 50. Total = 145; Count = 4; Average = 36.25. The condition avoids division by zero.

B · Identify the algorithm

FOR Pass ← 1 TO 4
    FOR Index ← 1 TO 5 - Pass
        IF Numbers[Index] > Numbers[Index + 1] THEN
            Temp ← Numbers[Index]
            Numbers[Index] ← Numbers[Index + 1]
            Numbers[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass

Array: 8, 3, 6, 2, 5. Name the method, explain the nested loops and Temp, and trace the final list.

Bubble sort, ascending order. Outer loop controls passes; inner loop compares adjacent values. Temp preserves a value while swapping. Final list: 2, 3, 5, 6, 8.

C · Spot the bug

Lowest ← 0
FOR Index ← 1 TO 5
    IF Numbers[Index] < Lowest THEN
        Lowest ← Numbers[Index]
    ENDIF
NEXT Index
OUTPUT Lowest

Array: 12, 8, 19, 5, 14. What is the intended purpose? What does it actually output? Correct the error.

It should find the minimum but outputs 0, because all values are positive. Start with Lowest ← Numbers[1] and compare from index 2. Correct output: 5.

Activity 5: Six-mark assessment

Question 1 · 3 marks

Result ← Numbers[1]
FOR Index ← 2 TO 6
    IF Numbers[Index] > Result THEN
        Result ← Numbers[Index]
    ENDIF
NEXT Index
OUTPUT Result

(a) State the purpose. [1]
(b) Describe how the algorithm achieves its purpose. [2]

Question 2 · 3 marks

An algorithm starts Counter at zero. It checks each number and increments Counter when the number is even.

(a) State its purpose. [1]
(b) Explain why the counter starts at zero. [1]
(c) What is the output for 3, 8, 12, 7, 10? [1]

Q1: Finds the largest array value [1]. Starts with the first value [1] and updates Result whenever a larger value is found [1].
Q2: Counts even numbers [1]; starts from zero to avoid an incorrect count [1]; output 3 [1].

Sum ← 0
FOR X ← 1 TO 10
    Sum ← Sum + X
NEXT X
OUTPUT Sum

In one sentence, state its purpose and predict its output.

The algorithm calculates and displays the sum of the integers from 1 to 10. Output: 55.
