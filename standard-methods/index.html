3. Algorithm investigation

For each mystery: identify the method, the variable that changes and the output. Trace the array by hand first.

Algorithm A

Total ← 0
FOR Index ← 1 TO 5
    Total ← Total + Numbers[Index]
NEXT Index
OUTPUT Total

Numbers: 4, 7, 2, 9, 3

Reveal explanation

Totalling. Total accumulates each value. Output: 25.

Algorithm B

Count ← 0
FOR Index ← 1 TO 5
    IF Marks[Index] >= 50 THEN
        Count ← Count + 1
    ENDIF
NEXT Index
OUTPUT Count

Marks: 45, 72, 38, 91, 60

Reveal explanation

Counting. Count increases for marks of 50 or above. Output: 3.

Algorithm C

Minimum ← Numbers[1]
FOR Index ← 2 TO 5
    IF Numbers[Index] < Minimum THEN
        Minimum ← Numbers[Index]
    ENDIF
NEXT Index
OUTPUT Minimum

Numbers: 18, 7, 25, 4, 13

Reveal explanation

Minimum. Minimum stores the smallest value found so far. Output: 4.

25–37 min

4. Pseudocode detective

Identify the algorithm, describe how it works and calculate the result. Compare your explanation with a partner.

Mystery 1: What does Highest track?

Highest ← Values[1]
FOR X ← 2 TO 6
    IF Values[X] > Highest THEN
        Highest ← Values[X]
    ENDIF
NEXT X
OUTPUT Highest

Values: 14, 8, 27, 19, 6, 22

Show solution

Maximum method. The algorithm starts with the first value and replaces Highest when it finds a larger value. Output: 27.

Mystery 2: Two methods together

Total ← 0
FOR X ← 1 TO 5
    Total ← Total + Marks[X]
NEXT X
Average ← Total / 5
OUTPUT Average

Marks: 60, 75, 80, 65, 90

Show solution

Totalling and averaging. Total = 370; output: 74.

Mystery 3: Why two loops?

FOR Pass ← 1 TO 4
    FOR Index ← 1 TO 5 - Pass
        IF Numbers[Index] > Numbers[Index + 1] THEN
            Temp ← Numbers[Index]
            Numbers[Index] ← Numbers[Index + 1]
            Numbers[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass

Numbers: 9, 4, 7, 2, 5

Show solution

Bubble sort ascending. Outer loop counts passes; inner loop compares adjacent values. Temp preserves a value during a swap. Final list: 2, 4, 5, 7, 9.

6. Exam-style assessment · 10 marks

Answer independently before opening the mark scheme.

Q1 (2 marks). Explain the difference between linear search and bubble sort.

Q2 (2 marks). Describe how a totalling algorithm works.

Q3 (2 marks). Explain why a counter is normally initialised to zero.

Q4 (2 marks). Find the maximum and minimum in 12, 18, 7, 25, 14.

Q5 (2 marks). Explain how to calculate the average of eight marks.

Reveal mark scheme (self-mark)
  1. Linear search checks values sequentially to find a target; bubble sort compares and swaps adjacent values to sort a list.
  2. Initialise Total to zero and add each value to it.
  3. To begin counting at zero and count only qualifying occurrences.
  4. Maximum = 25; minimum = 7.
  5. Add all eight marks and divide the total by eight.

Responses are not submitted or saved. Copy them if you need to keep them.

7. Exit ticket

Homework: Five methods, one array

A school stores 20 marks in an array called Marks. Write pseudocode to:

  1. Calculate the total of all marks.
  2. Count how many students scored 50 or above.
  3. Find the highest mark.
  4. Find the lowest mark.
  5. Calculate the average mark.

Extension: Combine all five operations into one algorithm using a single traversal.
